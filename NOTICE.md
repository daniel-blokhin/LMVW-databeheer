# Ownership, attribution and reuse review

This is a refactored portfolio-oriented implementation based on supplied project code and schemas. The original project was collaborative. No assertion is made that one contributor owns all original code, data, documentation or design decisions.

No open-source licence has been assigned automatically. Confirm the applicable employment, collaboration and contractual rights with the relevant rights holders before publicly distributing source code or selecting a licence. A public repository and an open-source licence are separate decisions.

The repository includes independently generated synthetic data and does not include original tender documents, original notebooks, API credentials, private input workbooks, private GeoPackages or raw production API caches. Synthetic examples are not representations of actual housing plans or legal documents.

Public availability of an underlying data service does not automatically make the combined project dataset, confidential plan information, code or tender materials publishable. Review source terms, provenance and intended publication scope separately.

Replace this notice with an appropriate approved licence/attribution arrangement only after the rights review. Do not invent authorship or claim sole ownership of collaborative work in a CV.
