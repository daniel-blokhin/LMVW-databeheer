# Examples — one input, one export, one report

All files here are **synthetic** and safe to use for this technical demonstration, subject to the code ownership notice at the repository root.

| Directory | Contents | Meaning |
| --- | --- | --- |
| [`input/`](input/) | `plans.csv` and `api/*.json` | Single source dataset: 36 invented housing plans and BAG, BRK, DSO-shaped responses. No API key required. |
| [`output/database_ready/`](output/database_ready/) | 17 CSV tables, `manifest.json`, `schema.json`, `schema.sql` | Generated by Part 1 from the input above. This is **derived output**, not a second input dataset. |
| [`reports/`](reports/) | `report.html`, `preview.png` | Generated analytics of that same output (Part 2). The HTML works offline. |

To reproduce the process, run from the repository root:

```bash
python -m pipeline.run run --config config.yaml --report
```

The result is written to `data/runs/<run-id>/`, **not** into `examples/`. The generated run ID and run timestamp will differ. Compare the table structure, row counts and metrics rather than byte-for-byte equality between exports. The original raw input remains unchanged.

To verify the bundled sample export:

```bash
python -m pipeline.run verify examples/output/database_ready
```

**Important:** `data/private/` and `data/runs/` are local-only. Do not copy real deliveries or generated private reports into `examples/`, which is intended to be public on GitHub.
