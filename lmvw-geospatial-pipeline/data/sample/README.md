# Artificial test delivery

Every value in this directory is generated by `scripts/generate_sample_data.py`. Names, native-looking identifiers, cadastral labels and legal-document text are fictional. Coordinates are artificial shapes in RD New; they are not original project plan geometry. These files must not be described as actual Dutch housing statistics.

Eight plan records deliberately exercise four accepted records, four rejected records, a shared area key, a negative net capacity, a five-year bucket and missing/invalid fields. The API-shaped JSON fixtures model residential/non-residential VBO filtering, official pand references beyond the scope, boundary points, parcel overlaps, unique DSO text fetching and unverified candidates.

Regenerate from the repository root after installation:

```bash
python scripts/generate_sample_data.py
```

Fixture mode reads these responses directly and makes no network calls. Transport/pagination behaviour is tested separately with explicit mocked HTTP sessions. Live mode never falls back to these files.
